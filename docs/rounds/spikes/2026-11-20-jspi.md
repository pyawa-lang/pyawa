# Spike：JSPI 栈切换可行性（2026-11-20）

- **问题**：wasm 宿主能否让 VM 内的阻塞等待挂起到 JS 事件循环并恢复？
- **实验**：`tests/wasm/proto_jspi.js`（dev `8a8f989f`）：`clock_sleep_ns` 以
  `WebAssembly.Suspending` 包装、`pa_exec_string` 以 `WebAssembly.promising` 包装；
  实测阻塞 `time.sleep(0.005)` 挂起→JS 定时器→恢复（run `44715783595` wasm job PASS）。
- **结论**：**JSPI 可行**，Node 24 / 现代浏览器可用；但旧 WebView 需要 Asyncify 构建。
- **裁决（2026-11-21）**：**不作为内核架构驱动，不采用代码进 `main`**；JSPI/Asyncify 属于
  宿主 adapter 选型（`ADR-002`）。原因：asyncio 的实现架构不应反向定义内核（Lua 定位）。
